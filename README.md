# CSV → Markdown 表格

把 CSV 粘进左边，右边直接出 Markdown 表格。纯前端单页，没有后端，
数据全程留在你自己的浏览器里。

**打开就用：** 把仓库拉下来，用任意静态服务器起 `index.html` 即可
（`python3 -m http.server` 就够）。ES module 需要 http 协议，`file://` 打不开。

## 它处理了这些

- 引号里的逗号、分号、制表符（`a,"b,c",d` 是 3 列，不是 4 列）
- 成对引号转义（`"a""b"` → `a"b`）
- 引号里的换行（转成 `<br>`，不会把一行劈成两行）
- 单元格里的竖线（转义成 `\|`，不会把表格结构劈开）
- CRLF 与 LF 给出同一份输出
- 分隔符自动识别，且**引号感知** —— 引号里的分号是数据，不参与投票
- 各行列数不齐时补齐并明确报一条警告，不静默
- 三种对齐；关掉表头时补一个空表头行
- 单元格内容按数据渲染（`textContent`），标签不会被当成 HTML

## 质量是怎么关的

先搭闸门，再写功能。快闸门共 41 条检查（行为 20 / 结构 17 / 变异体 4），
浏览器闸门 11 条，两条都在 CI 上跑，结论回写成 PR 评论。

- **纯核心**：`src/engine.mjs` 不碰任何 I/O，有扫描器在守（先剥注释再找）
- **变异体**：4 条断言被故意改坏过一次，证明它们真的在守，不是装饰
- **两把独立的尺**：浏览器闸门的期望值是手写字面量，不是引擎算出来的
- **心跳**：定时运行留下带时间戳的正向痕迹,平台悄悄停用 cron 时它会喊
- **送达核对**：`attest` 独立回头确认那条评论真的存在，并钉在本次 run 上

已知的盲区如实写在 `AGENTS.md` 的「测不出来的」一节里，没有拿启发式假装补上。
